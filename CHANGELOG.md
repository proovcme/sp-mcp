# Изменения

## 0.2.7 — 2026-11-19

- Подключён публичный каталог Федерального информационного фонда стандартов Росстандарта. Доступны поиск и листание СП и ГОСТ, карточки с датами, сведения о замене и ссылки на изменения и поправки.
- Проверка сопоставляет карточки Росстандарта и Российского института стандартизации, показывает расхождения и покрытие каждого источника. Карточки в интерфейсе помечены отдельно и ведут к официальному просмотрщику.
- Добавлен [обзор государственных источников](docs/SOURCES.md) для дальнейшего подключения нормативных текстов.

## 0.2.6 — 2026-11-18

- Проверка разделяет наблюдаемый статус документа и подтверждённость на заданную дату. Для прошлого и будущего текущая карточка не даёт подтверждения. Неизвестные или недатированные изменения оставляют редакцию неподтверждённой.
- Сетевые обращения поиска и проверки ограничены общим временем и количеством запросов. При исчерпании бюджета доступная часть выдачи сохраняется. Адрес перенаправления проверяется до загрузки.
- Индекс обновляет записи по изменившимся источникам и удаляет устаревшие поисковые сегменты и векторы. При первом запуске поисковый индекс пересобирается из сохранённых снимков. Если используются локальные эмбеддинги, их индекс нужно подготовить заново.
- Тексты и фрагменты листаются вместе. Поиск внутри документа ограничивает количество собранных совпадений.
- Для PDF требуется однозначное обозначение по титульным данным. Старые снимки PDF доступны для чтения, для их повторной индексации нужно открыть источник заново.
- Веб-сервис проверяет допустимые HTTP Host и типы входных данных. В публичном режиме HTTP MCP и операции с проектами недоступны.

## 0.2.5 — 2026-11-14

- Поиск инженерной системы в каталогах по основному существительному, а не длинному уточнению; профильные внутренние и наружные сети канализации обнаруживаются без модели и заранее загруженного корпуса.
- Сначала фрагменты со всеми понятиями запроса; учитывается близость слов. Упоминания в других дисциплинах и частичные совпадения показываются отдельно.
- Полные названия из каталогов защищены от перезаписи короткими перекрёстными ссылками; повторы источников больше не занимают места документов в выдаче.
- Оформительские и товарные стандарты не опережают профильные СП при общем поиске системы. Автоматическая загрузка ограничена двумя документами и тремя попытками.
- Сохраняется вводная строка перечисления, в том числе «не распространяется»; исправлены обозначения старых СП с двумя дефисами и распознавание номера пункта с завершающей точкой.

## 0.2.4 — 2026-11-14

- Расширенное оглавление: пункты, глубокие подпункты и буквенные перечисления с иерархией и переходами к исходному тексту.
- Переключение краткого и подробного режима, поиск по номеру или полному тексту пункта, постраничная загрузка больших оглавлений.

## 0.2.3 — 2026-11-14

- Таблицы HTML показываются прямо в тексте с исходными объединениями ячеек; отдельный просмотр использует подписи источника.
- Сохраняется выравнивание псевдографических таблиц из оригинала; поддержано отображение Markdown-таблиц без исполнения HTML источника.
- Публичный режим VPS ограничивает число одновременных операций и частоту запросов, не создаёт очередь тяжёлых задач и останавливает новые загрузки при достижении бюджета диска.

## 0.2.2 — 2026-11-14

- Недействующие нормативы скрываются по умолчанию в поиске, фрагментах и библиотеке; флаг `include_inactive` возвращает исторические документы.
- Статус берётся из свежих явных наблюдений источников. Неизвестный или конфликтующий статус остаётся видимым с пометкой, без утверждения актуальности.
- Понятийное расширение обнаружения в каталогах: запрос о дымоудалении находит общие требования пожарной безопасности вентиляции, даже когда исходного слова нет в названии.
- Приоритет содержательных нумерованных пунктов над краткими заголовками; счётчик учитывает документы, найденные только в тексте.

## 0.2.1 — 2026-11-14

- Развёртывание под `/sp/`: примеры Caddy и systemd с отдельным пользователем, серверной базой и ограничениями ресурсов.
- Оглавление распознаёт буквенные пункты приложений и исключает числовые подписи к рисункам.

## 0.2.0 — 2026-11-14

- Встроенный веб-интерфейс: `sp-mcp web`, общая библиотека, чтение, редакции, сравнение и проверки.
- Автоматическое оглавление по заголовкам разделов и приложений; переход к основному тексту, устранение повторов печатного содержания.
- Поиск без модели: русские словоформы, BM25, опечатки и инженерный словарь понятий.
- Поиск в буквальных каталогах по значимому слову; обнаружение пожарных СП в рубрике приказов МЧС.
- Адресные фрагменты текста, отдельная группа смежных документов и регрессия холодного запроса со словоформами.
- Отдельный необязательный режим локальных эмбеддингов с возобновляемой подготовкой индекса.
- Выбор проекта и исходника «Увязки» в GUI; предварительный просмотр и сохранение нормативной связи.
- Защита записи сеансовым токеном и проверкой Origin; оболочка входа для HTTP с Bearer-токеном.

## 0.1.0 — 2026-11-14

Первая рабочая версия.

- MCP по stdio и Streamable HTTP, CLI и общее JSON API.
- Поиск по каталогам ГОСТ/СП Российского института стандартизации и обнаруженным источникам МегаНорма.
- Локальный полнотекстовый поиск по открытым документам.
- Неизменяемые снимки оригиналов и извлечения, SHA-256 и история проверок.
- Чтение HTML-пунктов, таблиц и ограниченное чтение PDF без OCR.
- Сверка статуса документа, состава изменений и расхождений дат.
- Пакетная проверка нормативных ссылок и сравнение редакций.
- Мост в «Увязку»: версия неутверждённого анализа, проверка исходника проекта и идемпотентная запись.
- Синтетические регрессии, MCP modern/legacy, HTTP API и опциональные проверки живых источников и «Увязки».

Не реализованы: полная нормативная база, семантический поиск, OCR, фоновый мониторинг,
автоматическая применимость к объекту и пользовательский веб-интерфейс.
