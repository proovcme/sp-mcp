# Изменения

## 0.2.0 — 2026-11-14

- Встроенный веб-интерфейс: `sp-mcp web`, общая библиотека, чтение, редакции, сравнение и проверки.
- Автоматическое оглавление по заголовкам разделов и приложений; переход к основному тексту, устранение повторов печатного содержания.
- Поиск без модели: русские словоформы, BM25, опечатки и инженерный словарь понятий.
- Поиск в буквальных каталогах по значимому слову; обнаружение пожарных СП в рубрике приказов МЧС.
- Адресные фрагменты текста, отдельная группа смежных документов и регрессия холодного запроса со словоформами.
- Отдельный необязательный режим локальных эмбеддингов с возобновляемой подготовкой индекса.
- Выбор проекта и исходника «Увязки» в GUI; предварительный просмотр и сохранение нормативной связи.
- Защита записи сеансовым токеном и проверкой Origin; оболочка входа для HTTP с Bearer-токеном.

## 0.1.0 — 2026-11-14

Первая рабочая версия.

- MCP по stdio и Streamable HTTP, CLI и общее JSON API.
- Поиск по каталогам ГОСТ/СП Российского института стандартизации и обнаруженным источникам МегаНорма.
- Локальный полнотекстовый поиск по открытым документам.
- Неизменяемые снимки оригиналов и извлечения, SHA-256 и история проверок.
- Чтение HTML-пунктов, таблиц и ограниченное чтение PDF без OCR.
- Сверка статуса документа, состава изменений и расхождений дат.
- Пакетная проверка нормативных ссылок и сравнение редакций.
- Мост в «Увязку»: версия неутверждённого анализа, проверка исходника проекта и идемпотентная запись.
- Синтетические регрессии, MCP modern/legacy, HTTP API и опциональные проверки живых источников и «Увязки».

Не реализованы: полная нормативная база, семантический поиск, OCR, фоновый мониторинг,
автоматическая применимость к объекту и пользовательский веб-интерфейс.
