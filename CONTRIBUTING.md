# Участие в разработке

Для запуска нужны Python 3.11+ и uv:

```bash
uv sync --locked --group dev
uv run ruff check src tests
uv run ruff format --check src tests
uv run python -m pytest -q
uv build
```

Перед изменением прочитайте [AGENTS.md](AGENTS.md) и [архитектуру](docs/ARCHITECTURE.md).

Для адаптеров источников добавляйте синтетические регрессии: несколько редакций, отмену,
будущую дату введения, неполную выдачу, конфликт источников и недоступность сети.
Не сохраняйте скопированные нормативные корпуса в тестах. Обычные тесты должны работать без сети.

Живые источники проверяются отдельно:

```bash
uv run python -m pytest tests/test_live.py -m live -q
```

Сетевая проверка фиксирует состояние источника в момент запуска, а не универсальную юридическую гарантию.
Данные загрузки и отчёты остаются в локальном пользовательском хранилище.

В pull request укажите проблему, изменившееся поведение и выполненные проверки.
Документацию обновляйте вместе с контрактами. Не меняйте неопределённость на «подтверждено» ради прохождения теста.
