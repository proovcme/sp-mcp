# Сообщения о безопасности

Не публикуйте токены, рабочие базы, персональные данные и закрытые документы в issues.
Для непубличного сообщения об уязвимости используйте GitHub Private Vulnerability Reporting,
если оно включено: вкладка **Security → Report a vulnerability**.

В отчёте достаточно версии, минимальных синтетических шагов воспроизведения и ожидаемого результата.
Актуальная поддерживаемая ветка — `main`; выпуски 0.1.x получают исправления по мере обнаружения проблем.

Сервер принимает документы только с явно разрешённых HTTPS-источников и учитывает robots.txt.
HTTP по умолчанию слушает loopback; внешняя привязка требует токен. Мост «Увязки» запускается только
через явно заданную локальную команду и сохраняет неутверждённый анализ через её MCP.
